引入：文件传输的需求

在网络中传输文件是最基本的需求之一。虽然现在有很多方式可以传输文件（如HTTP下载、云存储、即时通讯等），但FTP（File Transfer Protocol，文件传输协议）仍然是最经典、最标准的文件传输协议。

FTP的历史比HTTP还要悠久——它最早在1971年就被提出了（RFC 114），经过多次修订，现在的版本是RFC 959。FTP的设计目标是提供一个标准的、可靠的方式来在网络上传输文件。

FTP的工作原理

FTP与其他应用层协议有一个显著的不同：它使用两个TCP连接。

控制连接：用于传输命令和响应，使用21端口。控制连接在整个会话期间保持打开状态。客户端通过控制连接发送命令（如LIST、RETR、STOR），服务器返回响应（如状态码和消息）。

数据连接：用于传输文件数据，使用20端口（主动模式）或随机端口（被动模式）。每次传输文件或目录列表时都会建立一个新的数据连接，传输完成后关闭。

这种分离设计使得FTP可以在传输文件的同时接收命令。例如，你可以在文件传输过程中发送ABORT命令取消传输。

FTP的命令和响应

FTP使用文本命令进行通信。常见的命令包括：

  • USER username：指定用户名
  • PASS password：指定密码
  • LIST：列出当前目录的文件
  • RETR filename：下载文件
  • STOR filename：上传文件
  • CWD directory：切换目录
  • PWD：显示当前目录
  • MKD directory：创建目录
  • DELE filename：删除文件
  • QUIT：退出登录

服务器的响应是一个三位数字码加上文本消息：

  • 1xx：肯定预备响应（操作已开始，需要另一个命令来完成）
  • 2xx：肯定完成响应（操作成功完成）
  • 3xx：肯定中间响应（命令已接受，需要进一步信息）
  • 4xx：暂时否定响应（暂时性错误，可以重试）
  • 5xx：永久否定响应（永久性错误，不应重试）

FTP主动模式

FTP有两种数据连接的建立方式：主动模式和被动模式。

主动模式（Active Mode，PORT）的工作过程：

  1. 客户端从一个随机端口（如1025）向服务器的21端口建立控制连接
  2. 客户端发送PORT命令，告诉服务器自己的IP地址和一个随机端口（如1026）
  3. 服务器从20端口主动向客户端的指定端口（1026）发起数据连接
  4. 数据传输开始

主动模式的问题：服务器主动向客户端发起连接，如果客户端有防火墙，这个入站连接可能会被阻止。这就是为什么主动模式在现代网络中经常无法工作的原因。

FTP被动模式

被动模式（Passive Mode，PASV）解决了主动模式的防火墙问题：

  1. 客户端从一个随机端口向服务器的21端口建立控制连接
  2. 客户端发送PASV命令，请求服务器开放一个端口
  3. 服务器回复一个随机端口号（如2024）
  4. 客户端从另一个随机端口向服务器的2024端口发起数据连接
  5. 数据传输开始

在被动模式下，所有连接都是由客户端发起的，这样就不会被客户端的防火墙阻止。现代FTP客户端默认使用被动模式。

匿名FTP

匿名FTP（Anonymous FTP）允许用户使用anonymous作为用户名，通常不需要密码（或使用邮箱地址作为密码）来访问FTP服务器上的公开文件。匿名FTP常用于分发开源软件、文档、RFC文档等公共资料。

TFTP：简单文件传输协议

TFTP（Trivial File Transfer Protocol，简单文件传输协议）是一个极其简单的文件传输协议，基于UDP（端口69）。

TFTP的特点：

  • 基于UDP：使用UDP而不是TCP，开销更小
  • 极其简单：只支持读取和写入操作，没有目录浏览、用户认证等功能
  • 无认证：不需要用户名和密码
  • 小型化：协议实现非常小，适合嵌入式设备

TFTP的典型应用场景：

  • 网络设备启动：路由器、交换机等网络设备通过TFTP加载操作系统镜像
  • 无盘工作站启动：无盘工作站通过TFTP获取启动文件
  • 配置文件管理：网络管理员通过TFTP备份和恢复设备配置

TFTP的局限性：

  • 不可靠：基于UDP，没有内置的可靠性机制（虽然TFTP自己实现了简单的确认和重传）
  • 安全性差：没有认证和加密
  • 功能有限：只支持读写操作
  • 文件大小限制：默认块大小512字节，最大文件大小约32MB（可以通过选项扩展）

总结

FTP是互联网中最经典的文件传输协议，使用控制连接和数据连接分离的设计，支持主动和被动两种模式。TFTP是一个极简的文件传输协议，基于UDP，主要用于网络设备的启动和配置管理。

虽然现在HTTP下载和云存储已经取代了FTP的很多应用场景，但理解FTP的工作原理对于网络工程师仍然很重要，因为很多网络设备仍然使用FTP/TFTP进行配置管理和固件升级。

练习题

1. FTP使用几个TCP连接？

答案：B

解析：FTP使用2个TCP连接：控制连接（端口21）用于传输命令和响应，数据连接（端口20或随机端口）用于传输文件数据。

2. FTP被动模式相比主动模式的优势是什么？

答案：B

解析：被动模式下所有连接都由客户端发起，不会被客户端防火墙阻止。主动模式下服务器主动向客户端发起数据连接，可能被防火墙阻止。

3. TFTP基于_____协议，使用端口69。

答案：UDP

解析：TFTP（简单文件传输协议）基于UDP协议，与FTP基于TCP不同，TFTP更加简单轻量。

4. FTP控制连接和数据连接分别使用什么端口？各自的作用是什么？

答案：控制连接使用21端口，用于传输FTP命令和服务器响应，整个会话期间保持打开。数据连接使用20端口（主动模式）或随机端口（被动模式），用于传输文件数据，每次传输时建立，传输完成后关闭。

解析：FTP的双连接设计使得命令和数据可以分离传输，用户可以在文件传输过程中发送其他命令。

5. 以下哪个是TFTP的典型应用场景？

答案：C

解析：TFTP常用于网络设备（路由器、交换机）的启动和配置管理，因为TFTP实现简单，适合嵌入式设备使用。
