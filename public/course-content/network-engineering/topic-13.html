课题13：路由基础与路由表

核心术语

路由器
工作在网络层的设备，根据IP地址和路由表决定数据包的转发路径，连接不同的网络。
路由表
路由器维护的一张表，记录了目的网络、下一跳地址、出接口等信息，路由器根据这张表决定数据包往哪转发。
静态路由
由管理员手动配置的路由条目，不会自动变化。适合小型网络或末梢网络，管理成本高但可控性强。
默认路由
当路由表中没有匹配条目时使用的路由，通常指向互联网出口。目的地址为0.0.0.0/0，也叫默认网关。
下一跳
路由表中指示的下一个路由器的IP地址，数据包需要先到达下一跳，再由下一跳继续转发。
最长前缀匹配
路由器在查找路由表时，选择与目的地址匹配的最长前缀（最精确）的路由条目。这是路由选择的核心规则。
管理距离
衡量路由来源可信度的数值，越小越可信。直连路由为0，静态路由为1，OSPF为110，RIP为120。
度量值
衡量到达目的网络路径优劣的指标，如跳数、带宽、延迟等。同一协议中度量值越小路径越优。

路由器：网络世界的"十字路口指挥员"

如果把互联网比作一个巨大的公路网，那路由器就是每一个十字路口的指挥员。它的职责很简单：收到一个数据包，看看目的地是哪，然后决定往哪个方向转。

路由器的工作过程

当路由器收到一个IP数据包时：

  1. 解封装：去掉数据链路层的帧头，取出IP数据包
  2. 查路由表：用目的IP地址在路由表中查找匹配条目
  3. 转发决策：
    • 找到匹配：把数据包从对应的出接口转发出去
    • 没找到匹配：如果有默认路由就按默认路由转发，否则丢弃并返回ICMP目的不可达
  4. 重新封装：给数据包加上新的帧头（下一跳的MAC地址），从出接口发出

注意：转发过程中，IP头部的源和目的地址不变，但数据链路层的帧头帧尾会每跳都重新生成。

路由表：路由器的"导航地图"

路由表是路由器转发数据包的核心依据。每台路由器都维护着一张路由表，记录了"要去某个网络，应该往哪走"。

路由表的典型结构

目的网络 前缀长度 下一跳 出接口 来源 管理距离 度量值
192.168.1.0 /24 直连 GE0/0 直连 0 0
10.0.0.0 /8 192.168.1.254 GE0/1 静态 1 0
172.16.0.0 /16 10.0.0.1 GE0/1 OSPF 110 20
0.0.0.0 /0 203.0.113.1 GE0/2 静态 1 0

各字段含义：

  • 目的网络 + 前缀长度：要去的网络
  • 下一跳：下一个路由器的IP地址
  • 出接口：从哪个物理接口转发出去
  • 来源：这条路由是怎么学到的（直连、静态、OSPF等）
  • 管理距离：路由来源的可信度（越小越可信）
  • 度量值：路径的优劣指标（越小越优）

最长前缀匹配原则

路由表里可能有多条路由都能匹配同一个目的地址。路由器怎么选？

规则是最长前缀匹配：选择前缀长度最长（最精确）的那条路由。

举例

路由表里有两条路由：

  • 192.168.0.0/16 → 下一跳 A
  • 192.168.1.0/24 → 下一跳 B

目的地址是192.168.1.100。两条路由都能匹配，但/24比/16更精确，所以选择下一跳B。

这就像你要去"北京市海淀区中关村大街1号"，如果有两条路——一条通向"北京市"，一条通向"海淀区中关村大街"——你当然选更精确的那条。

路由的来源

路由表中的路由有三种来源：

1. 直连路由（管理距离0）

路由器接口配置了IP地址并启用后，自动产生的路由。可信度最高。

2. 静态路由（管理距离1）

管理员手动配置的路由。适合小型网络或末梢网络（只有一个出口的网络）。

优点：简单、可控、不消耗带宽 缺点：网络拓扑变化时需要手动修改，不适合大型网络

3. 动态路由

路由器之间通过路由协议（如OSPF、RIP、BGP）自动交换路由信息。适合大型网络。

优点：自动适应网络变化 缺点：消耗带宽和CPU资源，配置更复杂

默认路由

当路由表中没有匹配的条目时，路由器会使用默认路由（也叫默认网关）。

默认路由的目的地址是 0.0.0.0/0，匹配所有地址。它是路由表的"兜底方案"。

你家路由器就有一条默认路由，指向运营商的路由器。当你访问百度时，你的路由器不知道百度的服务器在哪，就把数据包发给运营商，让运营商去想办法。

本课小结

  • 路由器根据IP地址和路由表转发数据包，连接不同的网络
  • 路由表记录目的网络、下一跳、出接口等信息，是转发的核心依据
  • 最长前缀匹配：多条路由匹配时，选择前缀最长（最精确）的
  • 路由有三种来源：直连（自动）、静态（手动）、动态（协议）
  • 默认路由（0.0.0.0/0）是兜底方案，匹配所有目的地址
  • 管理距离衡量路由来源可信度，直连0 < 静态1 < OSPF110 < RIP120

练习题

1. 路由器根据什么信息来决定数据包的转发方向？

答案：B

解析：路由器工作在网络层，根据数据包的目的IP地址查找路由表，决定从哪个接口转发以及下一跳地址。

2. 路由表中有两条路由：192.168.0.0/16和192.168.1.0/24，目的地址为192.168.1.100，应选择哪条？

答案：B

解析：根据最长前缀匹配原则，/24比/16更精确，所以选择192.168.1.0/24这条路由。

3. 默认路由的目的地址是________。

答案：0.0.0.0/0

解析：默认路由用0.0.0.0/0表示，匹配所有目的地址，是路由表中最后的兜底方案。

4. 以下哪种路由的管理距离最小（最可信）？

答案：C

解析：直连路由管理距离为0，是最可信的路由来源。静态路由为1，OSPF为110，RIP为120。

5. 静态路由和动态路由各有什么优缺点？

答案：静态路由：优点是简单、可控、不消耗带宽；缺点是不能自动适应网络变化，适合小型网络。动态路由：优点是自动学习和适应网络变化；缺点是消耗带宽和CPU，配置复杂，适合大型网络。

解析：选择静态还是动态路由取决于网络规模和管理需求。小型末梢网络用静态，大型复杂网络用动态。
